## Enter a mission profile

Each profile opens with its scientific identity, a model cockpit, a figure wall, a planned-work feed, related reading connections and a reading playlist. Its complete engineering dossier follows: original models, derivations, interfaces, data, uncertainty, trades, verification cases, failure analysis and cited primary resources.

| Profile room | What is visible | Controlled detail behind it |
| --- | --- | --- |
| Mission identity | Original investigation, mission name, question and testable hypothesis | Exact title and stable project ID in the source registry |
| Model cockpit | Method, variables, conventions and operating envelope | Governing expressions, derivation, assumptions and boundary conditions |
| Artifact wall | Architecture, data blueprint and included or planned scientific visuals | Figure captions, model methods and input/output hashes |
| Data observatory | All included numerical tables and complete proposed field maps | CSV headers, units, missingness, schemas and provenance |
| Investigation feed | Proposed engineering work packages | Specified evidence, execution criteria and versioned artifacts required for closure |
| Mission connections | Shared cited resources, supplied disciplines and included illustrations | Transparent connection register; no inferred physical dependency or team relationship |
| Reading playlist | Routes from the concept to data, decisions or execution | Direct navigation to the full engineering sections |
