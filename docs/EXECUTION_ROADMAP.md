# ATLAS research execution roadmap

This is a portfolio development framework, not a promise that 117 investigations can be completed within one schedule or budget. All projects remain in the catalog. Select an execution cohort according to scientific value, data readiness, expertise, access and independent validation resources.

## Shared capabilities

| Capability | Useful project connections | Evidence to produce |
|---|---|---|
| Time, frames and telemetry | ASCEND, EagleSat, CatSat, attitude and ephemerides | Clock/frame interface tests and reproducible decoding |
| Calibrated imagery | OCAMS, SKYSURF, NIRCam, segmentation and planetary geology | Flat/dark/PSF/geometry uncertainty and injection recovery |
| Transport and inverse models | Thermal systems, hydrology, QTN, neutron stars and phase behavior | Conservation checks, boundary sensitivity and identifiability |
| Selection-aware statistics | Exoplanets, radio populations, winds, ecology and education | Independent-unit validation and selection-function documentation |
| Spectroscopy and chemical evidence | Meteorites, mineral mixtures, hot springs and carbon capture | Reference standards, blanks, mixture degeneracy and provenance |
| Systems integration | Structure, EPS harness, avionics and outreach | Requirement-to-test traceability and controlled interfaces |

## Example first execution cohort

Choose a manageable subset without removing the rest of the portfolio:

- **A01:** numerical precision and visualization; cheap synthetic test cases and clear analytic checks.
- **C05:** a carefully scoped exoplanet catalog ingestion/classification benchmark; keep occurrence inference separate.
- **C02/C12/I11:** background measurement, calibrated archive access and foreground modeling using one common data contract.
- **E06:** benign thermal-network correlation with independently logged power and temperature.
- **B23:** hydrologic decision support where catchment data and stakeholder decisions can be grounded.
- **H02:** OCAMS calibration reproduction on a small identified public product set.
- **F02:** source-linked communication evaluation once human-subjects review and accessible tasks are established.

These are suggested sequence choices, not a ranking of project importance. Community partners and original researchers can change scope or sequence.

## Work packages per project

1. Define question, observable, decision and authority for requirements.
2. Confirm available data and collaborators; estimate statistical power or parameter identifiability.
3. Build a baseline model and an independently checked numerical/measurement test.
4. Collect or acquire calibration data, then freeze the analysis.
5. Evaluate against withheld evidence; quantify performance, error and uncertainty.
6. Produce scientific figure, reproducible methods, limitation statement and communication artifact.

For resource planning, enumerate people-hours by role, compute/storage, instrument access, calibration, field/flight coordination, review, insurance/permissions where applicable, and contingency. Obtain quotes before dollar estimates. Shared archive infrastructure can reduce repeated setup but does not replace specialist review.

## Fusion and engineering model handoff

Mechanical projects require a controlled parameter table, units, coordinate frame, keep-outs, material records, interface control documents, assumptions, and simulation/measurement correlation. E05, G07, I06 and I09 identify candidate Fusion workflows. This release supplies mathematical design models and conceptual assembly context; it does not claim native Fusion CAD or flight-qualified geometry was created.
